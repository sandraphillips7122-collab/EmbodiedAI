# 本文件由 `pip freeze` 从实际运行环境的 .venv 提取，**版本为实测可用组合**。
# 它只是**参考清单**：`pyproject.toml` 刻意不声明 dependencies，
# 是为了避免 `pip install -e .` 从错误的源拉取 CUDA 版 torch 等重依赖。

# ⚠️ Windows / 中国大陆网络的两个关键点（详见 docs/env_decision.md）
# --------------------------------------------------------------
# 1) CUDA 版 torch 必须用带 `+cuXXX` 的 wheel。
#    清华 PyPI 镜像上的 `torch` 是 **CPU-only**（124 MB，cuda_available=False），
#    必须从阿里云 pytorch-wheels 镜像取（约 2.5 GB）：
#       pip install torch==2.9.1+cu128 torchvision==0.24.1+cu128 \
#           --index-url https://mirrors.aliyun.com/pytorch-wheels/cu128
#    因此下面这两行**不能**直接用普通 PyPI 源安装。
# 2) 其余纯 Python 包用清华源即可：
#       pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
#
# 已知无害的项
# -----------
# - `torchcodec` 在本机 DLL 加载失败，lerobot 会自动回退到 `pyav`（功能等价）。
# - `opencv-python` 与 `opencv-python-headless` 同时存在（分别是 mani_skill 与
#   lerobot 的传递依赖）；本项目未依赖此冲突，实际运行正常。
